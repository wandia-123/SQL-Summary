A collection of SQL concepts and examples presented in Jupyter Notebook format.

About
This repository provides concise SQL summaries and practical examples to help users understand, review, and apply common database concepts.

Getting Started
Clone the repository:
bash
git clone https://github.com/wandia-123/SQL-Summary.git
Open the repository in Jupyter Notebook or JupyterLab:
bash
jupyter notebook
Select and run a notebook to explore the SQL examples.
Requirements
Jupyter Notebook or JupyterLab
Access to a SQL database supported by the notebook environment
